# AqarCheck

AqarCheck is a real estate project designed to help users search for properties and easily access important information about them.

## About the Project

AqarCheck provides a simple way for users to explore available properties, view their details, and make better decisions when searching for real estate.

## Features

- Search for properties
- Filter properties based on different criteria
- View property details
- Display property prices
- Display property locations
- Manage user information
- Store and manage property data

## Team

This project was developed as a team project.
